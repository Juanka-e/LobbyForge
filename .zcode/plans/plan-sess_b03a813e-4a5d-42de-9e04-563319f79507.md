# Tüm Soruların Cevapları + Uygulama Planı

## Sorularınıza net cevaplar

### 1. Plugin SQL tablo/migration nasıl olacak?
**Cevap: Plugin'ler SQL migration gönderemez ve göndermemeli.** Doğru tasarım budur:
- **Oyun durumu** → `gameSessions.state` JSONB (host yazıyor, plugin okuyor — bugün çalışıyor)
- **Sunucu ayarları** → `pluginsEnabled.settings` JSONB (READ/WRITE_PLUGIN_SETTINGS permission)
- **Büyük veri (leaderboard vb.)** → gelecekte `plugin_data` generic key-value tablosu (host-owned, plugin'e raw SQL vermeden)
- **Neden?** Güvenlik. Community plugin'lerine `@lobbyforge/db` erişimi yok, `DbClient` yok, raw SQL yok. Bu bilinçli bir tasarım kararı.

**Uygulama:** `plugin_data` generic storage API eklenecek (host-owned tablo, plugin SDK'dan `ctx.storage.get/set` ile erişim).

### 2. Discovery'de şikayet/report butonu
**Cevap:** Şu an hiç raporlama altyapısı yok. Eklenecek:
- `instance_reports` tablosu (reporter, reason, detail, status)
- Discovery kartlarında "..." menüsünde "Report" butonu
- Admin moderation panelinde "Reports" bölümü
- `POST /api/directory/{id}/report` (auth/guest-aware, rate-limited)

### 3. Feature flag ile official vs self-host ayrımı
**Cevap:** `LOBBYFORGE_DEPLOYMENT_MODE=official|self_host` tek flag, doğru çalışıyor.**
- Self-host: discovery, marketplace, multi-server GİZLİ (zaten `isOfficialDeployment()` ile gate'li)
- Self-host kullanıcılarının bu sürüme ihtiyacı yok — env'i `self_host` (veya boş) bırakırsalar hiç görmüyorlar
- Ek flag'a gerek yok

### 4. GitHub yönetimi
**Cevap:** Repo public-ready değil. Düzeltilecekler:
- LICENSE 15 byte placeholder → tam AGPL-3.0 metni
- `CONTRIBUTING.md` root'a taşı
- `SECURITY.md` (vulnerability reporting policy)
- `.github/ISSUE_TEMPLATE/` (bug, feature, security)
- `.github/PULL_REQUEST_TEMPLATE.md`
- `.github/dependabot.yml`
- CI'ya Docker image build/push ekle (`ghcr.io/lobbyforge/web`)

### 5. Host banner
**Cevap:** `servers` tablosunda `bannerUrl` yok (user'da var). Eklenecek:
- `servers.bannerUrl` kolonu + migration
- Upload API + modal (user banner pattern'ından kopyala)
- Lobby sidebar header'da render (Discord gibi ismin arkasında banner)
- Discovery kartında da göster

### 6. Production Docker Stack
**Cevap:** Hiç production stack yok (spec-only). Eklenecek:
- `docker-compose.prod.yml` (nginx + web + postgres + redis + livekit + ws-gateway)
- `infra/nginx/` config dosyaları

- `install.sh` — tek komut kurulum (domain sor, SSL üret, başlat)
