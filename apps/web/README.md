# @lobbyforge/web

The main Next.js 15 (App Router) application for LobbyForge.

Houses the lobby shell (voice channels, chat, members panel), the admin
dashboard (health, settings, members, roles, channels, bandwidth), the first-run
setup wizard, and the API routes for auth, presence, channels, messages,
invites, roles, LiveKit tokens, and the plugin host surface.

See [`docs/WEB_APP.md`](../../docs/WEB_APP.md) for the full route and feature map.
